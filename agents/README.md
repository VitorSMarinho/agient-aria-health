# 🤖 Agentes ARIA — Agient

## O que é o ARIA?

O ARIA é um sistema multi-agent de inteligência clínica desenvolvido 
pela **Agient** para transformar dados hospitalares em decisões estratégicas.

---

## Agentes disponíveis

| Agente | Descrição | Acesso |
|---|---|---|
| 🟢 `aria_indicadores` | Análise de KPIs operacionais | **Demo pública** |
| 🔒 `aria_quadro_paciente` | Análise clínica do paciente | Demonstração exclusiva |
| 🔒 `aria_financeiro` | Saúde financeira e anomalias | Demonstração exclusiva |
| 🔒 `aria_estoque` | Controle de medicamentos | Demonstração exclusiva |
| 🔒 `aria_estrategico` | Insights estratégicos | Demonstração exclusiva |

## 🔒 Agentes exclusivos

Os demais agentes são componentes proprietários da **Agient** e estão 
disponíveis apenas para demonstração agendada.

Eles incluem análise clínica restrita a médicos, monitoramento 
financeiro, controle de estoque crítico e inteligência estratégica 
— todos integrados à arquitetura Medallion do Databricks.
